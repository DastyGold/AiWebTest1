# Персональный сайт Сергея Сапегова

Добро пожаловать в репозиторий моего персонального сайта! Этот проект представляет собой многостраничный веб-сайт, созданный с использованием чистого HTML, CSS и JavaScript без фреймворков.

## О проекте

Этот сайт создан как демонстрация моих навыков веб-разработки и включает в себя несколько разделов:

- **Главная страница** - с модальным окном для взаимодействия с нейросетью GigaChat
- **Резюме** - подробная информация обо мне и моем опыте
- **Книги** - подборка рекомендуемых книг по различным темам
- **Контакты** - способы связи со мной
- **Обратная связь** - форма для отправки сообщений

## Основные функции

### Интеграция с GigaChat API
Сайт включает в себя интеграцию с GigaChat API от Сбер, которая позволяет пользователям взаимодействовать с нейросетью через модальное окно на главной странице.

### Адаптивный дизайн
Сайт полностью адаптирован для просмотра на различных устройствах - от мобильных телефонов до десктопов.

### Современный интерфейс
Используются современные CSS-свойства, включая:
- Градиенты
- Анимации и переходы
- Flexbox для верстки
- Темная тема оформления

### Форма обратной связи
Реализована форма обратной связи с валидацией данных и индикатором загрузки.

## Технологии

- **HTML5** - структура страниц
- **CSS3** - стилизация и анимации
- **Vanilla JavaScript** - интерактивность и функциональность
- **GigaChat API** - интеграция с нейросетью
- **Node.js/Express** - backend сервер
- **SQLite** - локальная база данных для хранения сообщений

## Установка и запуск

### Предварительные требования
- Node.js (версия 14 или выше)
- npm (менеджер пакетов Node.js)

### Установка зависимостей

```bash
npm install
```

### Настройка переменных окружения

1. Скопируйте файл `.env.example` в `.env`:

```bash
cp .env.example .env
```

2. Получите учетные данные для GigaChat API в личном кабинете разработчика Сбер: [https://developers.sber.ru/](https://developers.sber.ru/)

3. Заполните переменные в файле `.env`:

```env
GIGACHAT_CLIENT_ID=ваш_client_id
GIGACHAT_CLIENT_SECRET=ваш_client_secret
```

### Запуск проекта

```bash
# Запуск сервера
npm start

# Или запуск в режиме разработки с автоматической перезагрузкой
npm run dev
```

Сервер запустится на порту 5000. Откройте в браузере [http://localhost:5000](http://localhost:5000)

## Интеграция с GigaChat API

Для работы с GigaChat API необходимо:

1. Получить Client ID и Client Secret в личном кабинете разработчика Сбер
2. Установить их в файле `.env` в переменных `GIGACHAT_CLIENT_ID` и `GIGACHAT_CLIENT_SECRET`
3. Убедиться, что сервер запущен для обработки запросов к API

API эндпоинты:
- `POST /api/ask` - для запросов к нейросети
- `POST /api/feedback` - для формы обратной связи
- `GET /api/feedback` - для получения всех сообщений обратной связи

## Безопасность

### 🔑 Переменные окружения
Все секреты (учетные данные GigaChat API, пароли) хранятся в файле `.env`, который **исключён из Git** через `.gitignore`. В репозитории находится только файл-шаблон `.env.example` с заглушками.

### 🛡️ Защита API
- **Rate Limiting** — не более 30 запросов в минуту с одного IP
- **CORS** — доступ разрешён только с указанных доменов
- **Helmet** — защита от распространённых веб-уязвимостей (XSS, clickjacking и др.)
- **Валидация** — все входные данные проверяются на тип, длину и формат
- **SQL-инъекции** — используются параметризованные запросы

### 🔐 Административный доступ
Эндпоинт `GET /api/feedback` защищён базовой аутентификацией. Учётные данные задаются через переменные окружения `ADMIN_USERNAME` и `ADMIN_PASSWORD`.
